# HASP · Reading a neighbourhood from data

Hands-on workshop notebook for **Leeds Digital Festival**. Combines three open,
LSOA-level indices for Leeds / West Yorkshire to produce a short, defensible list of
neighbourhoods to act on.

**Run it:** open `HASP_workshop.ipynb` in Google Colab → `Runtime → Run all`.
